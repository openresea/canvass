# Contributing

Use a separate branch and fictional test data. Install `requirements-dev.txt`, run unit tests, then the PostgreSQL and browser suites for changes to authentication, roles, questionnaires or submissions. See README for the isolated test cluster requirements.

Keep question text and survey choices configurable. Do not add organisation names, real addresses, deployment account identifiers or secrets as defaults. Preserve response snapshots when changing questionnaire behaviour, and test authorization on the server as well as in the UI.

Keep the licence and required notice intact. Before publication, check that the security contact in SECURITY.md is monitored.

## Contributions and licensing

Bug reports and suggestions are welcome. Code contributions are paused until a contributor agreement is in place that permits both noncommercial distribution and separate commercial licensing. Do not submit third-party code without permission from its copyright holder.
